# باشگاه دانش خرید عالی

مرکز راهنماهای علمی و آموزشی خرید عالی؛ با هدف یادگیری ساده، کشف و انتخاب آگاهانه.

## مشاهده سایت
پس از فعال‌سازی GitHub Pages، سایت از این نشانی در دسترس خواهد بود:
https://kharideali.github.io/danesh-club/

## بخش‌های فعلی
- [باشگاه تلسکوپ](https://kharideali.github.io/aperture-guide/)
- [باشگاه میکروسکوپ](https://kharideali.github.io/microscope_guide/)

## انتشار سایت
در مخزن GitHub به مسیر **Settings → Pages** بروید. در قسمت **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید؛ سپس شاخه **main** و پوشه **/(root)** را تعیین و ذخیره کنید. فایل اصلی سایت `index.html` در ریشه مخزن قرار دارد.

## توسعه بعدی
موضوعات تازه مانند ابزارهای آموزشی، بازی‌های فکری و راهنماهای علمی به‌تدریج به صفحه اصلی اضافه خواهند شد.
