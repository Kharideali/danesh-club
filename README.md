# باشگاه دانش خرید عالی

وب‌سایت فارسی و راست‌چین باشگاه به‌صورت چندصفحه‌ای و ایستا ساخته شده است؛ صفحهٔ اصلی در `index.html` و صفحه‌های اختصاصی هر دنیا در `categories/<slug>/index.html` قرار دارند. داده‌های دسته‌ها و زیرموضوع‌ها در `content.js` متمرکز هستند، منطق نمایش و تعامل‌ها در `app.js` است و سبک‌ها در `styles.css` تعریف شده‌اند.

## افزودن یا ویرایش محتوا

عنوان، معرفی، رنگ و زیرموضوع‌های هر دسته را در شیء مربوط در `content.js` ویرایش کنید. تصویرها در `assets/images/` هستند تا از ریشهٔ پروژه و مسیرهای تو‌در‌تو به‌صورت نسبی قابل دسترسی باشند. برای تغییر تصویر یا متن معرفی، fallback ایستای همان دسته را نیز در `categories/<slug>/index.html` همگام کنید؛ این کار تضمین می‌کند محتوای اصلی حتی بدون JavaScript قابل مشاهده بماند. برای افزودن دستهٔ تازه، صفحهٔ ایستای آن را بسازید و مسیرش را در `manus-routes.json` و `sitemap.xml` ثبت کنید.

راهنماهای تلسکوپ و میکروسکوپ به نشانی‌های مستقل خود پیوند می‌دهند؛ محتوای مخزن‌های آن راهنماها بخشی از این پروژه نیست.

## اجرا و ساخت ایستا

پروژه وابستگی بسته‌ای ندارد و با یک سرور فایل ایستا اجرا می‌شود:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

فرمان ساخت، صفحهٔ اصلی، پنج صفحهٔ دسته، فایل‌های مشترک، تصویرها، favicon، robots و sitemap را در `dist/` گرد می‌آورد.
